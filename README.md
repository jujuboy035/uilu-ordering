# 奎陆中日手提

中文／日文下单系统。前端部署在 Sites，账号、数据库和账号管理函数运行在 Supabase。

## 目录

- `frontend/index.html`：当前本地最新页面，包含界面、业务逻辑、翻译词典和内嵌 Supabase SDK（2.117.3）。无需打包即可作为静态网页部署。
- `supabase/functions/kuilu-manage-accounts/index.ts`：后台分配账号和重设密码的 Edge Function。
- `supabase/sql-history/`：现有数据库已执行过的 SQL 源码留档。
- `tests/`：双语页面、表单默认值及后台权限检查；`tests/sql/` 为带回滚的数据库检查脚本。
- `CONTRIBUTING.md`：两人协作方式。
- `DEPLOYMENT.md`：预览、后台设置和正式发布说明。

## 当前功能

- 管理员分配自定义账号和密码，无需邮箱验证；客户不自行注册。
- 中日地址簿、下单、订单查询、常用品名保存。
- 品名支持色卡、样衣以及直接输入；包装默认袋子；申报币别默认 USD。
- 无中国或日本邮编、英文品名、运输箱数、照片上传及取货时间段输入。
- 顾客下单 → 工作人员分配司机 → 司机取货 → 中国仓库收货；也支持仓库直接收货。
- 实重与长宽高由司机或仓库填写；订单号按中国日期加四位流水号生成。
- 客户资料按账号隔离；管理员、中国工作人员和司机的权限由数据库控制。
- 货物页和确认页已包含本地最新的紧凑布局调整。

## 本地检查

需要 Node.js 22 或更新版本。在仓库目录运行 `npm test`，不需要安装依赖。

静态预览可在仓库目录运行 `python -m http.server 8080 --directory frontend`，然后打开 http://localhost:8080 。
页面仍连接现有 Supabase 项目，本地登录后的业务操作会写入该项目。
账号管理函数只接受允许的线上来源；本地预览不会自动开放创建账号或重设密码。

## 版本与数据

本仓库存放源码，不含客户数据库、测试订单导出、账号密码或服务端密钥。
页面中的 Supabase 项目地址与 `sb_publishable_` 公钥是浏览器连接配置；实际数据权限由登录身份和 RLS 控制。

**提交代码不会自动发布网站。** 本仓库未配置部署自动化；合并、测试后再单独发布。
数据库 SQL 为历史留档，不是新项目的一键安装程序；请先阅读 `supabase/sql-history/README.md`。
